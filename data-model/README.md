# Data Model

This folder is reserved for a **sanitized data-model diagram** representing the architecture used for the dashboarding solution.

When adding the diagram, remove or anonymize:

- internal database/schema names;
- proprietary table and column names;
- internal identifiers;
- server names, hostnames and file paths;
- credentials or connection information;
- confidential business rules.

Recommended file name:

`data-model.png`

The diagram should focus on the relationships between source data, ETL transformations, the analytical data layer, monitoring/Data Quality and BI dashboards.
